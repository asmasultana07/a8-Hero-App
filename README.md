## 🔗 Key Overview

- **App Discovery** - Browse and explore a collection of apps with detailed information, including ratings, reviews, and download counts.
- **Live Search & Filtering** - Instantly search apps by title with a fast, case-insensitive live search experience.
- **App Details & Reviews** - View comprehensive app details along with a visual review breakdown using an interactive chart.
- **Install & Manage Apps** -  apps with one click, persist installations using localStorage, and manage them from the My Installation page.
- **Ratings Breakdown Chart** - Interactive visual chart (bar representation) for user ratings.
- **Loader Animation** - Smooth loader appears during all data fetches and searches.
- **Dynamic Toasts** - On every install/uninstall action, toast notifications appear with the specific app’s name.
- **Sort by Downloads** - Easily sort installed apps by download count in ascending or descending order.
- **Responsive & User-Friendly UI** - Fully responsive layout with smooth navigation, loading animations, and clear error handling.
- **Error Handling** - Custom error pages, loading indicators, and informative messages for invalid routes or missing apps.
- **Responsiveness** - responsive for all devices.
  
## 🧩 Core Pages

| Page                  | Description                                                             |
| --------------------- | ----------------------------------------------------------------------- |
| **Home Page**         | Hero section with tagline, app showcase, and trusted metrics.           |
| **All Apps Page**     | A searchable grid of all apps, featuring a dynamic loader and filters.           |
| **App Details**       | Displays app information, chart breakdown, and controls for installation and uninstallation. |
| **Installation Page** | Lists locally installed apps with uninstall option.                     |
| **404 Page**          | Handles invalid routes using Lottie animation and a back-home button.   |
